# Md. Shazid Hossain — Portfolio Website

A responsive, single-page portfolio website built from the supplied portfolio proposal, Markdown hero notes, and updated CV.

## Preview locally
1. Extract this project folder.
2. Open `index.html` in a browser. For best results, use VS Code Live Server.
3. Keep the `assets` folder and `Md-Shazid-Hossain-CV.pdf` beside `index.html`.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `shazid-portfolio`).
2. Upload **all contents** of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to provide the live URL.

## Included
- Seven requested sections: Hero, About, Professional Experience, Skills, Selected Work, Video Showcase, Contact & Footer.
- Warm white / near-black / restrained orange visual system.
- Responsive desktop and mobile layout.
- Extracted original photos and design images from the supplied CV PDF.
- YouTube thumbnail links and Facebook Reel links from the CV.
- Downloadable CV PDF.

## Important review notes
- The CV lists INNI as ending November 2026. The portfolio marks it as Present based on the current project context; confirm this is still accurate before publishing.
- The CV contains overlapping date ranges for some roles. The website preserves the supplied dates and does not invent freelance/part-time labels.
- The contact section intentionally shows email only. The CV phone number is not published because public display was not explicitly confirmed.
- Social profile URLs were not supplied in the CV, so none have been invented.
- Some YouTube thumbnails load from YouTube's thumbnail service and require an internet connection.
